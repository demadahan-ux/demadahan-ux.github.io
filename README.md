# Demarie Moyo — portfolio

Professional portfolio for customer support, operations, and automation.

Website: https://demadahan-ux.github.io/

## Hosting

GitHub Pages serves the main branch from the repository root. The site is static HTML, CSS, and JavaScript; no build step or paid API is required. Keep `.nojekyll` at the root.

## Contact

The contact page offers discovery calls, chat-only inquiries, and a Ready to hire project brief. Forms prepare an email for the visitor to review and send. Automatic emails, booking confirmation, and Google Sheets intake are not active.

Visitors can request a WhatsApp reply by providing their own number in the inquiry form. Demi’s phone number is excluded from the public site source and resume.

## Work samples

Project screenshots are anonymized. The employee dashboard demo uses fictional records; CSV imports stay in browser memory. Client workspaces and private inquiry data are not included.

The Charcoal & Sage theme is in `professional.css`; the demo uses `demo/demo.css`. Fonts are served locally; licenses are in `assets/FONT-LICENSES.txt`.
