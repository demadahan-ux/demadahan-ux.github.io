THE GOAL

Keep useful guidance
close to the call.

During a customer conversation, an agent may need a process guide, a policy reference, or help deciding what to check next. I built this app to organise those support resources in one place.

The starting point is the call type. From there, agents can find the relevant workflow or reference category, with AI support available alongside the app.

WHAT I BUILT

A structured starting point
for everyday support.

  1. 01

    A call-type menu

    Dedicated entry points for cancellations, refunds, damage claims, mobile-app escalations, duplicate billing, and other recurring support categories.

  2. 02

    A topic-based FAQ hub

    Common questions organised as selectable topics, including memberships, payment methods, mobile-app concerns, account lookup, and claims.

  3. 03

    Connected reference navigation

    The app’s navigation brings together call types, FAQs, quality guidelines, wash information, and a leave tracker.

  4. 04

    An embedded AI help-desk agent

    An embedded Jotform AI agent gives the app an additional support channel. The interface includes Chat, Voice, and History, with the agent presented as a Help Desk Specialist.

WHAT THIS PROJECT DEMONSTRATES

Support knowledge,
turned into a usable tool.

Workflow thinking

Organising customer concerns into clear, relevant entry points that support an agent’s next action.

Practical use of AI

Adding an AI agent within a support workspace, alongside structured reference material.

Frontline perspective

Using customer service experience to shape the categories, terminology, and information an agent needs.
